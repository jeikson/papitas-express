# Créditos de las fotos

Las fotos de **bebidas** y **salsas** son de **Open Food Facts** (base de datos abierta de
productos), cuyas imágenes se publican bajo **Creative Commons BY-SA**. Se descargaron,
se recortaron a un cuadrado con fondo crema y se redujeron a 480×480 px con
`tools/` (ver historial del proyecto).

Si en algún momento quieres reemplazarlas por fotos propias del negocio, basta con
sobrescribir el archivo con el mismo nombre: la app las toma automáticamente.
